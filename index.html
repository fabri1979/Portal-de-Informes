CONCEPTO CLAVE — LAS DOS CLASES DE EMPRESAS DEL PORTAL

Sepa esto antes de continuar

En el portal existen DOS clases de empresas. Es MUY importante no confundirlas:

1. EMPRESAS DE USUARIOS:

Son las empresas a las que usted les da el servicio. Ejemplo: Credigestion, Empresa ABC.

Usted las registra con su NOMBRE, su LOGO (usted lo sube) y una DESCRIPCION.

Cada usuario que usted crea PERTENECE a una empresa de usuarios.

Cuando ese usuario inicia sesion, ve EL LOGO DE SU EMPRESA en la barra superior

y en todas sus pantallas — como si el portal fuera de esa empresa.

Se administran en: Admin -> Empresas de Usuarios.

2. EMPRESAS DE INFORMES:

Son las empresas sobre las que existen informes dentro del portal.

Sus logos aparecen en sus tarjetas y acompanan a SUS informes.

Se administran en: Admin -> Empresas de Informes.

Las dos listas son INDEPENDIENTES. Una misma empresa puede estar en ambas si lo necesita,

pero se registran por separado, cada una con su propio logo.

CODIGO SQL — Copie COMPLETO y pegue en el SQL Editor de Supabase
-- ============================================================
-- PORTAL DE INFORMES CREDIGESTION - CREACION DE TABLAS v7.0
-- Pegue este codigo en Supabase SQL Editor y haga clic en Run
-- Las lineas con -- son comentarios. Supabase las ignora.
-- ============================================================

-- TABLA 1: Empresas de usuarios (a quienes da el servicio; su logo
--          es el que ven sus usuarios al entrar)
CREATE TABLE IF NOT EXISTS empresas_usuarios (
  id          UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  nombre      VARCHAR(200) UNIQUE NOT NULL,
  descripcion TEXT,
  logo_url    TEXT,  -- logo que ven sus usuarios al entrar
  correo_soporte VARCHAR(200),  -- correo que ven sus usuarios en Ayuda
  creado_en   TIMESTAMPTZ DEFAULT NOW()
);

-- TABLA 2: Usuarios (cada uno pertenece a una empresa de usuarios)
CREATE TABLE IF NOT EXISTS usuarios (
  id                 UUID    DEFAULT gen_random_uuid() PRIMARY KEY,
  nombre             VARCHAR(200) NOT NULL,
  email              VARCHAR(200) UNIQUE NOT NULL,
  password_hash      VARCHAR(255) NOT NULL,
  rol                VARCHAR(20)  DEFAULT 'usuario',
  empresa_usuario_id UUID REFERENCES empresas_usuarios(id),
  activo             BOOLEAN  DEFAULT true,
  intentos_fallidos  INTEGER  DEFAULT 0,
  bloqueado_hasta    TIMESTAMPTZ,
